Ejercicio 12 (Dividir y conquistar el TP)

Un grupo de N estudiantes se dispone a hacer un TP de su materia favorita (Sistemas Operativos). 
Cada estudiante conoce a la perfección cómo implementarTp() y cómo experimentar(). Curiosamente, cada una de estas acciones puede ser llevada acabo de manera independiente por cada uno, así que decidieron dividirse el trabajo.
Acordaron dividir el trabajo en varias etapas. En cada etapa, todos los estudiantes deben primero implementarTp(), y recién cuando todos hayan terminado, pueden empezar a experimentar(). Luego, para poder comenzar la siguiente etapa y volver a implementar, todos deben haber terminado de experimentar con la etapa anterior.
Se pide diseñar un programa concurrente que utilice procesos y que modele esta situación utilizando semáforos.

```c
// Shared
int n; // Estudiantes
int implementar_count=0;
int experimentar_count=0;

sem implementar(n);
sem experimentar(0);
sem mutex(1);

// --- Estudiante ---

while(1){
    implementar.wait();
    
    implementarTp();
    // Avisar que ya se implemento
    mutex.wait();
    implementar_count ++;
    if(implementar_count == n){ // Soy el ultimo
        implementar_count = 0;
        for(int i = 0, i < n){
            experimentar.signal(); // Dar n tikets para experimentar
        }
    }
    mutex.signal();
    
    experimentar.wait();
    
    experimentar();
    
    // Avisar que ya se experimento
    mutex.wait();
    experimentar_count ++;
    if(experimentar_count == n){ // Soy el ultimo
        experimentar_count = 0;
        for(int i = 0, i < n){
            implementar.signal(); // Dar n tickets para implementar
        }
    }
    mutex.signal();
}

```
