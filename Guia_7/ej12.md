Ejercicio 12
Teniendo en cuenta el ejercicio anterior, considerar el siguiente código:
```
void saludo(void) {
    char nombre[80];
    printf("Ingrese su nombre: ");
    gets(nombre);
    printf(nombre);
    exit(0);
}
```
Dado que la función saludo nunca retorna y, por ende, no interesa el valor de su return address, ¿es segura la segunda llamada a printf?

No, para empezar, gets nos permite escribir de corrido hacia direcciones mas grandes, pasando el "limite" de nombre (buffer overflow), permitiendo asi sobreescribir valores en el stack, como el propio retunr de saludo, que en este caso no importa, pero de por si poder escribir el stack de un programa es una vulnerabilidad.
Luego teniendo en cuenta el printf podemos hacer un string format attack, que nos permita leer y escribir valores, del stack o potencialmente el return de printf.
